# F.R.I.D.A.Y. — Cloud Garden & Jarvis Integration

An advanced AI desktop assistant and interactive computer-vision system.

## Features
- **Cloud Garden UI**: Responsive dashboard with interactive companion, daily bloom, and real-time system metrics.
- **Hand Gesture Control & Gesture Lab**: MediaPipe-powered touchless gesture navigation and classification.
- **Musical Instruments Suite**: Play Air Piano, Air Guitar, and Air Tabla in real-time with optical hand landmark tracking.
- **Vision Studio & Quick Tools**: Real-time camera filters, calendar, notes, media controller, and system monitoring.
- **JARVIS (Mark IV) Engine Integration**: Seamlessly switch between FRIDAY and the autonomous Mark IV assistant engine with intelligent camera arbitration.
